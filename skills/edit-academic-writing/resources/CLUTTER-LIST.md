# Clutter List

Cut or replace these patterns. They add nothing to academic writing.

---

## 1. Dead Phrases (Delete Entirely)

These phrases signal that the writer is warming up. Cut them and start with the actual content.

| Dead Phrase | Action |
|-------------|--------|
| As it is well known | DELETE |
| As it has been shown | DELETE |
| It can be regarded that | DELETE |
| It should be emphasized that | DELETE |
| It is important to note that | DELETE |
| It is interesting to note that | DELETE |
| It is worth mentioning that | DELETE |
| It is worth noting that | DELETE |
| It goes without saying that | DELETE |
| Needless to say | DELETE |
| It has long been known that | DELETE |
| It is widely accepted that | DELETE |
| It is generally believed that | DELETE |

### Examples

```
BAD:  As it is well known, deep learning requires large datasets.
GOOD: Deep learning requires large datasets.

BAD:  It should be emphasized that the algorithm converges in O(n log n) time.
GOOD: The algorithm converges in O(n log n) time.

BAD:  It is interesting to note that the model fails on edge cases.
GOOD: The model fails on edge cases.
```

## 2. Empty Words (Delete)

These adverbs are suitable for speech but weak for writing. They pad without adding meaning.

| Word | Status |
|------|--------|
| very | DELETE |
| really | DELETE |
| quite | DELETE |
| basically | DELETE |
| generally | DELETE |
| actually | DELETE |
| essentially | DELETE |
| certainly | DELETE |
| definitely | DELETE |
| clearly | DELETE (unless referring to visual clarity) |
| obviously | DELETE |
| simply | DELETE |
| just | DELETE (when meaning "merely") |
| particular | DELETE (when vague) |
| specific | DELETE (when vague) |
| given | DELETE (when meaningless filler) |

### Examples

```
BAD:  The results are very significant.
GOOD: The results are significant.

BAD:  This is basically a greedy algorithm.
GOOD: This is a greedy algorithm.

BAD:  The method is quite efficient.
GOOD: The method is efficient.
```

## 3. Filler Transitions (Replace or Delete)

Professional writers use only AND/OR (for adding) and BUT/HOWEVER (for contrast). Everything else is padding.

| Filler | Replacement |
|--------|-------------|
| Furthermore, | DELETE or "Also," |
| Moreover, | DELETE or "Also," |
| In addition, | DELETE or "Also," |
| Additionally, | DELETE or "Also," |
| In conclusion, | DELETE (reader knows it's the conclusion) |
| To conclude, | DELETE |
| In summary, | DELETE (or use sparingly in long papers) |
| It is worth noting that | DELETE (just state it) |
| It is important to emphasize | DELETE (just state it) |

### Examples

```
BAD:  Furthermore, the model achieves 95% accuracy.
GOOD: The model achieves 95% accuracy.
      [OR] Also, the model achieves 95% accuracy.

BAD:  In conclusion, we have shown that X improves Y.
GOOD: We have shown that X improves Y.
```

## 4. Bureaucratic Language (Replace)

These words sound official but obscure meaning. Use plain English.

| Bureaucratic | Plain |
|--------------|-------|
| aforementioned | this, that, the |
| herein | here, in this paper |
| thereby | so, thus |
| utilize | use |
| utilization | use |
| facilitate | help, enable, allow |
| methodology | method |
| finalize | finish, complete |
| implement | do, carry out, apply |
| prior to | before |
| subsequent to | after |
| in order to | to |
| due to the fact that | because |
| in the event that | if |
| at this point in time | now |
| at the present time | now |
| for the purpose of | to, for |
| in the case of | if, when, for |
| with respect to | about, for, on |
| in terms of | DELETE or rephrase |
| on the basis of | based on, from |

### Examples

```
BAD:  We utilize the aforementioned methodology.
GOOD: We use this method.

BAD:  Prior to the experiment, we finalize the parameters.
GOOD: Before the experiment, we set the parameters.

BAD:  In order to improve accuracy, we implement regularization.
GOOD: To improve accuracy, we apply regularization.
```

## 5. "There Is/Are" Constructions (Rewrite)

These use weak "to be" verbs. Rewrite with stronger verbs.

| Weak | Strong |
|------|--------|
| There are many ways to solve this problem. | Many ways exist to solve this problem. |
| | The problem has many solutions. |
| There is a need for further research. | Further research is needed. |
| There was a long line of bacteria on the plate. | Bacteria lined the plate. |
| There are several factors that influence X. | Several factors influence X. |
| There is an association between X and Y. | X and Y are associated. |
| | X correlates with Y. |

### Examples

```
BAD:  There are many algorithms that can solve this problem.
GOOD: Many algorithms can solve this problem.

BAD:  There is evidence that suggests X causes Y.
GOOD: Evidence suggests X causes Y.
```

---

## 6. Redundant Pairs (Pick One)

When two words mean the same thing, one is redundant.

| Redundant Pair | Pick One |
|----------------|----------|
| each and every | each OR every |
| first and foremost | first OR foremost |
| various and sundry | various |
| full and complete | complete |
| true and accurate | accurate |
| basic and fundamental | fundamental |
| hopes and desires | hopes OR desires |
| thoughts and ideas | thoughts OR ideas |
| challenges and difficulties | challenges |
| successful solutions | solutions (solutions are already successful) |
| studies/examples | studies OR examples |
| illustrate/demonstrate | illustrate OR demonstrate |

---

## 7. Negative Constructions (Use Positive Forms)

Negative constructions are harder to process. Use positive equivalents.

| Negative | Positive |
|----------|----------|
| not honest | dishonest |
| not harmful | safe, harmless |
| not important | unimportant, minor |
| not significant | insignificant |
| not different | similar, identical |
| not the same | different |
| does not have | lacks |
| did not remember | forgot |
| did not pay attention to | ignored |
| did not succeed | failed |
| cannot be avoided | inevitable |
| not able to | unable to |

### Sentence-Level Examples

```
BAD:  I am not crazy about the movie but for its aesthetic elements.
GOOD: I only like the movie's aesthetic elements.

BAD:  She did not want to perform the experiment incorrectly.
GOOD: She wanted to perform the experiment correctly.

BAD:  The method does not have the ability to handle large inputs.
GOOD: The method cannot handle large inputs.
      [OR] The method lacks scalability.
```
