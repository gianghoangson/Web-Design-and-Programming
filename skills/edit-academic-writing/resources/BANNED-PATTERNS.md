# Banned Patterns

These patterns degrade academic writing. The em-dash (Section 1) is permitted with care; the remaining patterns are hard bans, no exceptions.

---

## 1. Em-Dash: Use With Care

**Rule**: The em-dash is permitted, used sparingly and with intent. Two patterns earn it; one is discouraged.

### Permitted

- **Matched-pair parenthetical.** Two em-dashes enclose an aside that complements the clause, especially when the aside carries its own commas or a list, where commas alone would blur and parentheses would bury it.
- **Single closing expansion.** One em-dash sets off a phrase at the end of a sentence that names, explains, or amplifies what came just before, and that phrase carries real content.

### Discouraged

- **The hollow emphasis dash.** A single dash before a short phrase whose only job is suspense, with no added content, the cadence that reads as manufactured drama. The test: if the phrase after the dash carries a name, list, explanation, or concrete image, it earns the dash; if it only manufactures a pause, cut it or use a colon.

### Examples

```
OK:    The method — which we call GRASP — achieves 95% accuracy.        (pair, aside)
OK:    Three factors — cost, time, and quality — determine success.     (pair, comma-list)
OK:    One resource stays non-critical — the proctor cap.               (single, names it)
AVOID: The result was clear — and that changed everything.              (hollow, no content)
```

### Still prefer the cleaner mark when it reads as well

- Comma for light pauses
- Parentheses for asides
- Colons for lists or amplification
- Semicolons for related independent clauses

## 2. Performative Contrast Ban

**Rule**: Do not state what something is *not* before stating what it *is*. The negation is scaffolding. State the positive claim directly.

### Detection Patterns

| Pattern | Example |
|---------|---------|
| Two-sentence split | "This is not X. It is Y." |
| Problem framing | "The problem is not X. The problem is Y." |
| "Not X, but Y" | "Not a bug, but a feature." |
| Profundity setup | "It is not just X, it is Y." |
| Reversal setup | "It is X, not Y." |
| Formal setup | "X is not the case, Y is." |
| Triple negation | "Not X, not Y, not Z. It is W." |

### The One-Sentence Test

Remove the negation sentence. If the meaning is preserved, the negation was doing nothing. Cut it.

### Fix Examples

**Pattern 1: Two-sentence split**
```
BAD:  The minimal experiment is not a shortcut. Its purpose is logical.
GOOD: The minimal experiment serves a logical purpose.

BAD:  Vision is not a grand statement about changing the world. It is a personal answer to practical questions.
GOOD: Vision is a personal answer to practical questions.

BAD:  This is not a productivity trick. It is a calibration tool.
GOOD: This is a calibration tool.
```

**Pattern 2: Triple negation**
```
BAD:  The most difficult writing skill is not clarity, not structure, and not precision. It is reading your own work as a hostile reviewer would.
GOOD: The most difficult writing skill is reading your own work as a hostile reviewer would.
```

**Pattern 3: The "not X but Y" redirect**
```
BAD:  The argument is not that you should publish before having results. The argument is that writing forces clarity.
GOOD: Writing forces clarity that research alone does not.
```

**Pattern 4: Profundity setup ("not just X")**
```
BAD:  Science is not just about discovery. It is an act of persuasion.
GOOD: Science is as much an act of persuasion as it is an act of discovery.
```

### When Negation Is Legitimate

**Two cases only**:

1. **Correcting a documented misconception**
   - The misconception must be specific and widespread
   - Evidence must be provided
   - Example: "Prior work assumed X; this is incorrect because [evidence]..."

2. **Stating scope boundaries**
   - Factual claims about what the work covers
   - Example: "This paper does not address Y" or "The method does not apply to Z"
   - Keep brief and move on

### Acceptable Alternatives

When contrast genuinely adds information, integrate it minimally:

| Alternative | Example |
|-------------|---------|
| "rather than" | "deployed as a substitute rather than a complement" |
| "but" in one sentence | "precise but frequently misused" |
| "though/while" | "While X is common, Y is more effective" |
| "more X than Y" | "more about persuasion than discovery" |

The key question: Does the Y claim stand on its own without the negation? If yes, cut the negation.
